成员使用说明

写给第一次使用的同学，照着做就行。只有组织成员可以发布和修改，其他人只能浏览。

一、你能做什么

发布动态

文字 + 图片，发布到对应的研究组。

修改 / 删除

随时改自己的内容，或删除不需要的内容。

仅成员可操作

非组织成员看不到入口，也无法修改。

二、发布一条动态（3 步）

  1. 打开发布页：向管理员要链接，或收藏 publish.html。
  2. 选择研究组：点你所属小组的卡片，会打开一个已填好标题前缀的 GitHub 页面。 第一次会让你登录 GitHub，用组织成员账号登录即可。
  3. 填写并提交：在标题后写标题，正文写内容，点绿色按钮 Submit new issue。几秒后网站会自动出现。

论文与成果：在发布页点「论文与成果」卡片，按模板填写 作者、会议/期刊、年份、链接， 提交后会显示在「论文」页。

三、加图片（2 步）

① 上传图片

点下面的按钮，打开 GitHub 上传页，把图片拖进去，再点 Commit changes。图片会存到仓库的 assets/uploads/。

上传图片到仓库 →

② 在正文里引用

回到动态正文，写一行：

![图片](文件名.jpg)

例如 ![图片](2026-11-lab.jpg)。不用写路径，网站会自动到 assets/uploads/ 里找。

小建议：文件名用英文或数字、不要空格；图片先压缩到 1–2 MB 以内，页面加载更快。 多张图就写多行 ![...]，会依次显示；图片可以点击放大。

四、修改 / 删除

修改

在网站动态卡片点「查看 / 编辑」进入该 Issue，点标题右上角的铅笔图标， 修改标题或正文后保存即可。

删除

在 Issue 页面点右上角 ⋯ → Delete issue；或者 Close issue 关闭（关闭后网站也会隐藏）。

五、常见问题

Q：点发布没反应 / 打不开？
确认已登录 GitHub，并且是组织成员。

Q：发布后网站没显示？
等几秒刷新；检查标题开头是不是 [研究方向]（模板已自动带好）；确认 Issue 没有被关闭。

Q：图片不显示？
确认图片已上传到 assets/uploads/；正文写的是 ![图片](文件名.jpg)；文件名大小写要一致。

Q：别人能改我的动态吗？
不能。只有组织成员有权限；非成员创建的 Issue 会被自动关闭，也不会显示在网站上。

六、给管理员

  • 成员发布页：/publish.html（不公开，私发成员收藏）
  • 图片目录：assets/uploads/
  • 修改页面内容：编辑 index.html / research.html 等后 push
  • 部署：推送到 main 后 GitHub Pages 自动构建（1–2 分钟）
  • 非成员 Issue 拦截：.github/workflows/guard-issues.yml
