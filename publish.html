谁能操作

只有本组织成员（拥有仓库写权限）才能创建、编辑、删除。其他人既看不到入口，也无法修改。

发布

点下方对应小组按钮，用 GitHub 账号登录后填写。需要配图时，先用「上传图片」把图传到仓库，再在正文引用即可。

编辑 / 删除

在网站动态卡片点「查看 / 编辑」进入 Issue，用铅笔图标编辑，或用右上角 ⋯ 删除。

上传图片（可选）

图片存放在仓库的 assets/uploads/，永久有效、随仓库版本管理。

① 上传

点下方按钮，把图片拖进页面 → 点 Commit changes。图片会存到 assets/uploads/，记下文件名。

管理已发布内容

点「编辑」修改标题/正文；点「删除 / 关闭」进入 Issue，在右上角 ⋯ → Delete issue 删除，或 Close 关闭（关闭后网站隐藏）。

操作步骤

  1. 登录 GitHub：确保已用组织成员账号登录。
  2. （可选）传图：点「上传图片到仓库」，把图拖进去并 Commit，记下文件名；在正文写 ![图](文件名.jpg)。
  3. 发布：点上面的小组卡片，打开预填模板，填写标题与正文后提交。
  4. 编辑：在网站对应动态点「查看 / 编辑」，进入 Issue 后点毛笔图标修改。
  5. 删除：在 Issue 页面点右上角 ⋯ → Delete issue（需有权限）。

说明：非组织成员创建的 Issue 会被自动关闭，且不会显示在网站上。 也可以用管理员账号直接到 GitHub Issues 管理全部动态。
